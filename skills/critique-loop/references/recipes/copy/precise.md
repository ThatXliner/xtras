# Precise

**Look:** documentation a smart friend would write: direct, calm, and impossible to misread. No personality on show, and none missing.
**Good for:** docs, READMEs, tutorials, API references, release notes, error messages.

## Voice

- **Conversational but not frivolous.** Like a knowledgeable friend explaining, not a marketer and not a legal notice. No slang, pop-culture references, zany phrasing or exclamation marks.
- **Talk to the reader as "you".** Not "we", not "let's".
- **Clear and direct beats warm.** If a friendly aside makes an instruction harder to follow, cut it.

## Instructions

- **Active voice;** say who does what.
- **Conditions before instructions:** "To view the file, click **View**", not the other way round.
- **No "please", "simply", "easy" or "quickly"** in steps. The reader decides what's easy.
- **No filler:** "please note", "at this time", "in order to".
- **Vary sentence openings;** a page where every line starts "You can" reads as generated.

## Clarity for everyone

- **Plain words for a global audience:** no jargon, buzzwords, idioms or culture-specific references.
- **Sentence case for headings, serial commas, unambiguous dates** (14 March 2026, not 3/14).
- **Descriptive link text** (not "click here") and alt text for every image.
