# Epic Indie

**Look:** big, acted-out, honest. Ambitious motion and sound on an indie budget, with every claim true.
**Good for:** game trailers, launch videos, explainer shorts, app promos.
**Source:** the xtras author's own taste file, built from rejections of real work. Each rule quotes the reaction it came from.

## Ambition

- **Epic means epic.** When the brief says "epic", "cinematic" or "go nuts", competent and safe is a fail. A trailer that reads like a slideshow was rejected as "this is an EPIC GAME TRAILER". Cutscenes for big moments (a strike, a silo, a hatch opening) need detail and weight.
- **Static is a fail.** Long holds, one slow push per shot and characters who only stand there were rejected as "the animation is very lacking". Verbs in the narration should be acted out.
- **Show, don't tell.** Too much on-screen or on-page text was rejected repeatedly ("way too much text to read", "my teammates say this is too much text"). Prefer visuals, motion and UI that carry the idea.

## Things that read as cheap

- **Cheesy, tacky, cringe.** Stock taglines and slogans ("never leave" was "a terrible catchphrase"), forced hype, a format that only works with a voice the project doesn't have.
- **The wrong style.** When a style was named, match the real thing: "Apple's liquid glass", not something that "looks like Candyland". A different look can be kept as its own option, but it doesn't satisfy the brief.
- **AI slop.** Generic gradients, glossy filler imagery, inconsistent characters between shots, anything that "looks like absolute slop".
- **Something that doesn't look like what it's meant to be.** "That barely looks like a hatch." Every object should read instantly.

## Sound

- **Vary the music between pieces.** The same track across a series was rejected ("the music is the same for all of them").
- **Music under speech stays under it.** Narration must be clearly audible ("the music is too loud" during narration). Check the loudest windows against where speech is.
- **Fit the genre.** Epic cinematic music for a trailer, faster and lighter (fast jazz) where the brief is playful. Royalty-free filler that fits nothing was rejected ("you don't need Kevin MacLeod").
- **No sound is better than bad sound.** Background noise or effects that make it worse should be cut ("let's remove the background noise for now").

## Truth

- **Every claim must be true now.** No "on the Mac App Store" before it is. Check availability, prices, features, dates and names against the project's real state.
- **Marketing for this product always ends on its call to action** (for Billion: a clear CTA to the app).

## Consistency over novelty

- **A style the user already liked beats a new experiment.** When a format worked, keep it consistent across pieces ("a consistent 2D format… like Rick's Clips") instead of reinventing it each time.
- **Keep what they asked to keep.** "Keep the reverse cymbals, I like it": when the user approves a detail, a revision must not lose it.
